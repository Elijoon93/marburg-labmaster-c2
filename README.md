# Marburg LabMaster C2 Academic

نسخه نهایی `1.2.0-final` پلتفرم دانشگاهی زبان تخصصی آزمایشگاه برای شیمی، کنترل کیفیت، میکروبیولوژی مواد غذایی، شیمی شیر و صنایع دارویی.

## اجرای برنامه

`https://elijoon93.github.io/marburg-labmaster-c2/`

## رابط نهایی

- Navigation Rail جمع‌شونده دسکتاپ
- Command Bar زمینه‌محور
- Dock پنج‌گزینه‌ای موبایل
- پنل More با شش مسیر تکمیلی
- Active State هماهنگ با ۱۰ Route واقعی
- بدون اسکرول افقی در دسکتاپ و موبایل
- Focus Visible و وضعیت‌های ARIA

## محتوای علمی

- ۵۰۱ اصطلاح تخصصی سه‌زبانه
- ۳۰ درس دانشگاهی و کارشناسی‌ارشد
- ۱۲ پرونده تصمیم‌گیری آزمایشگاهی
- ۸ قالب نگارش و ۸ محاسبه‌گر
- ۱۳ روش آزمایشگاهی، ۸ مکالمه و ۲۸ عبارت دانشگاهی
- مسیر B1 تا C1/C2

## نصب آیفون

Safari → Share → Add to Home Screen

داده‌های پیشرفت در `localStorage` همان مرورگر نگهداری می‌شوند. پیش از پاک‌سازی مرورگر، خروجی JSON تهیه شود.

## معماری انتشار

payload علمی تأییدشده حفظ شده و رابط نهایی از فایل‌های زیر فعال می‌شود:

- `professional-shell-v1.1.js`
