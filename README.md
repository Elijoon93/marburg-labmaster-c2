## معماری انتشار GitHub Pages

مخزن برای حفظ بانک علمی تأییدشده نسخه ۱.۲ از معماری Loader استفاده می‌کند:

1. `index.html` چهارده قطعه موجود در `payload/` را بازیابی و بازسازی می‌کند.
2. `professional-shell-v1.1.*` و `final-v1.2.js` رابط پذیرفته‌شده قبلی را فعال می‌کنند.
3. `app-v2-loader.js` لایه نسخه ۲ را از قطعات `app-v2.*.b64` با Hash کنترل‌شده بارگذاری می‌کند.
4. `sw.js` تمام فایل‌های لازم را برای اجرای آفلاین Cache می‌کند.

نسخه ZIP مستقل، برخلاف معماری مخزن، دارای `index.html` مستقیم و کامل است.

## انتشار

GitHub Pages باید از شاخه `main` و پوشه `/ (root)` منتشر شود. تمام مسیرها Relative هستند و برای Subpath مخزن طراحی شده‌اند.

## نصب Android

لینک برنامه را در Chrome باز کنید و از منو گزینه **Install app** یا **Add to Home screen** را انتخاب کنید. اجرای آفلاین فقط پس از نخستین بارگذاری کامل قابل ارزیابی است.

## نصب iPhone

لینک برنامه را در Safari باز کنید، Share را بزنید و **Add to Home Screen** را انتخاب کنید. Safe Area و متادیتای iOS در سورس لحاظ شده‌اند؛ پذیرش واقعی دستگاه هنوز باید انجام شود.

## ذخیره داده و حریم خصوصی

پروفایل و پیشرفت آموزشی فقط در `localStorage` همان مرورگر و دستگاه ذخیره می‌شوند. پیش از پاک‌سازی مرورگر یا تعویض دستگاه، از داخل برنامه خروجی JSON تهیه کنید. هیچ API Key، Token یا گذرواژه‌ای در سورس قرار ندارد.

## کنترل کیفیت

جزئیات آزمون‌ها در `QA_MANIFEST.json` ثبت شده است. آزمون مرورگر شامل ۱۰ Route و هشت اندازه نمایش از `320x700` تا `1440x1000` بوده و اسکرول افقی، خطای مرورگر و ID تکراری مشاهده نشده است. به‌علت محدودیت محیط آزمون، Local Storage با Adapter حافظه‌ای هم‌رفتار ارزیابی شده و آزمون Origin واقعی در مرحله Production باقی مانده است.

## محدودیت‌های باقی‌مانده

- بازخوانی مستقل خط‌به‌خط تمام ۵۰۱ مدخل توسط ویراستار زبان آلمانی
- ممیزی رسمی انطباق WCAG
