# Marburg LabMaster C2 Academic

وب‌اپ دانشگاهی زبان تخصصی آزمایشگاه برای شیمی، کنترل کیفیت، میکروبیولوژی مواد غذایی، شیمی شیر و صنایع دارویی.

## نسخه جاری

**Professional Navigation v1.1**

- Navigation Rail جمع‌شونده در دسکتاپ
- گروه‌بندی واقعی منوها: نمای کلی، یادگیری، آزمایشگاه، دانشگاه و انطباق، حساب یادگیری
- Command Bar زمینه‌محور با عنوان Route، جست‌وجوی سریع و پشتیبان
- Dock پنج‌گزینه‌ای مخصوص موبایل
- پنل More برای مسیرهای تکمیلی
- Active State روشن و همگام با هر View واقعی
- حفظ کامل محتوای علمی و داده‌های نسخه Academic v1
